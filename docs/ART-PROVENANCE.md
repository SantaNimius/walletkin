# Artwork provenance
Character artwork and animation layers were generated with an AI image tool and reviewed through explicit user approvals. Normal lineages and the five Anomaly forms use their individually accepted styles.
App assets under app/src/main/assets/canonical contain the runtime portraits, bodies, moving parts, blink frames and JSON rigs. Renderer transforms animate the layers; these are not separate prerecorded videos.
Anomaly package approval covers the body, ears/tail or wings/tail, eight octopus tentacles, four fractal fragment groups, snail eyestalks and blink frames. Missing appendages in body layers are intentional; assembled views restore them.
Static assembled previews validate layer placement and are not device screenshots.
Organic protocol/material trait sheets are concept art, not all implemented runtime appearances. The visual-system design is documented in TRAIT-VISUAL-SYSTEM.md.
