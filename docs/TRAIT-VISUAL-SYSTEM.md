# Walletkin — scalable visual trait composition (design proposal)
Status: reviewable art/design specification, not an implemented runtime change. Existing evidence detectors remain unchanged; canonical identity now uses explicit Genesis v2. Earlier copper Dragon examples refer to concepts before Riftdrake.

## Principle
A trait describes evidence and a visual influence; it is not necessarily an accessory or emblem. Many active traits can share a small set of visual channels. Hundreds of future trait definitions should not produce hundreds of attachments. Keep full trait meaning in Story/Data; give visual precedence to the strongest, distinctive influences.

## Visual channels
| Channel | Native transformation | Example |
| --- | --- | --- |
| Material | grain, translucency, roughness, reflection, inner energy | holder stabilizes stone/glass; staking gives settled internal resonance |
| Pattern | scale edges, fur flow, leaf veins, folded paper creases | Jupiter curved bands become scale/gill/glass structure, no circular decal |
| Core | one intrinsic seed/core/inset | actual Genesis folded-vane artwork, restrained species-specific scale |
| Eyes | glow, blink rhythm, focused movement | awake/quiet activity state without extra badges |
| Silhouette accents | existing tuft, fin edge, frond, panel detail | explorer extends existing detail; avoid changing approved anatomy |
| Motion | pulse, drift, breathing, detail reaction | swap creates transient flowing ripple; staking creates steady coherent pulse |
| Particles | small memory fragments or fine refractive glints | veteran/collector contributions merge into one restrained particle field |
| Habitat | species-specific background with activity influence | collector changes background relief motifs; roots strengthens native landscape lines |
| Ornament | one or two small native pins/inlays if genuinely suitable | NFT enamel pins on Ape, tiny original artworks inside Wisp shell |

## Composition rules
1. Preserve species silhouette, face, anatomy and approved medium. Never add legs/tails/wings to express ordinary wallet behavior.
2. Give each active trait one primary channel, plus at most one secondary influence.
3. Merge same-channel contributions. Multiple protocol/trading traits should blend scale/fur/glass patterns instead of stacking badges.
4. Keep one dominant material/pattern signature, two secondary details and one optional ambient layer at a time. Remaining evidence stays visible in Data and may influence motion or scene states.
5. Clamp glow, particle density and color shifts per medium. Make protocol geometry follow curvature, light, occlusion and texture. Physical inlay should have contact shadows.
6. Use evidence strength and recency only when supported by data; thresholds/decay remain a separate future implementation decision. Unknown never means absent or confirmed.
7. Separate intrinsic permanent Seekerborn verification from temporary interaction reaction. No Seeker trait when unverified in actual wallet rendering.
8. NFT interaction, holding NFTs and owning a verified collection are different evidence predicates. Current interaction detector must not silently be relabeled as ownership.
9. Use actual Genesis image shape from its metadata. Do not confuse it with SKR's split-S mark.
10. Protocol recognition is optional as a literal logo. On Dragon/Slime, curved material rhythm is preferred; explanations in Story/Data carry precise protocol attribution.
11. Full concept generation approval does not imply animation package approval. Approve final appearances collectively, then prepare modular packages.

## Future trait-definition schema
id, evidencePredicateId, family, strength, permanence, primaryChannel, secondaryChannel, speciesAdapter, priority, conflictGroup, sourceAsset, geometryBudget.
This is a planned data model, not a new detector registry or shipped code. A library can have many definitions while reusing the same material/pattern/motion primitives.

## Proposed composition pipeline
confirmed evidence -> normalized trait states -> resolve conflicts within each family -> select dominant channels -> blend restrained strengths -> adapt to species material -> preserve rig anatomy -> generate visual state and Story/Data explanations.
Stable wallet DNA seeds positioning/variation. Rescan changes influences after confirmed new evidence; effects must not depend on image-generation randomness in the shipped app.
